# Contributing to AMMA

Thank you for your interest in contributing to the Advanced Medical Morphological Analyzer (AMMA) project!

## How to Contribute

- **Bug Reports & Feature Requests:**
  - Open an issue describing the bug or feature in detail.
- **Pull Requests:**
  - Fork the repository and create a new branch for your feature or fix.
  - Write clear, concise commit messages.
  - Ensure your code builds and passes all tests (see CI status).
  - Add or update documentation and tests as needed.
  - Submit a pull request to the `main` branch.
- **Code Style:**
  - Follow modern C++ best practices (C++17 or later).
  - Use descriptive variable and function names.
  - Document public functions and modules.
- **Testing:**
  - Add tests for new features or bug fixes in the `tests/` directory.

## Community Standards

- Be respectful and inclusive.
- Provide constructive feedback.
- Help others when possible.

For major changes, please discuss them in an issue before submitting a pull request.

---

By contributing, you agree to abide by the [Code of Conduct](CODE_OF_CONDUCT.md).
